# متجر بازار | BAZAAR — Premium Arabic E-Commerce Platform

منصة تجارة إلكترونية عربية متكاملة واحترافية متخصصة في بيع المنتجات الغذائية الطبيعية والتموين المنزلي الموثوق (عسل النحل النقي، زيت الزيتون البكر الممتاز المعصور على البارد، التمور الملكية، زبدة المكسرات والكاكاو بدون سكر مكرر، والمنتجات المنزلية الأصيلة)، مصممة بهوية بصرية راقية **Premium Arabic UI** تجمع بين فخامة العلامات التجارية الغذائية وبساطة واجهات Apple بخط Cairo وتجربة RTL متكاملة.

---

## 🌟 نموذج العمل — البيع حسب الطلب (Order-Based Commerce)

يعمل المتجر بنموذج مبتكر وشفاف يضمن وصول المنتجات طازجة دون الحاجة إلى تخزينها لفترات طويلة:
1. **عرض المنتجات بحالات توفر شفافة:**
   - `متاح للطلب المباشر` (Available)
   - `حسب الطلب (يتطلب تأكيد التوفر لدى المورد)` (Needs Confirmation)
   - `غير متوفر حالياً` (Unavailable)
2. **التحقق وتأكيد الطلب:** عند وصول طلب جديد، يقوم المدير بمراجعة المورد وتأكيد توفر الدفعة الطازجة وسعر التكلفة.
3. **تجهيز الطلب:** يُفحص الطرد ويُغلف بمواد عازلة ومقاومة للصدمات لحماية البرطمانات والصفائح.
4. **التوزيع والإسناد (يدوي وتلقائي):** يتم إسناد الطلب لكابتن التوصيل المعتمد بناءً على منطقة التغطية أو تلقائياً للكابتن الأقل حملاً.
5. **المتابعة اللحظية:** يتابع العميل خط سير طلبه خطوة بخطوة من حسابه عبر جدول زمني تفاعلي.

## 👥 الأدوار الثلاثة في تطبيق واحد موحد

لا توجد مشاريع أو قواعد بيانات منفصلة؛ تطبيق واحد، قاعدة بيانات واحدة، ونظام مصادقة واحد محمي بصلاحيات مشددة على الخادم:

| الدور | الرابط الرئيسي | وصف الصلاحيات |
|---|---|---|
| **مدير المتجر (Administrator)** | `/admin` | لوحة تحكم شاملة لإدارة المنتجات، التكاليف، الأرباح التقديرية، اعتماد المندوبين، إدارة الموردين، وإسناد الطلبات. |
| **مندوب التوصيل (Delivery Agent)** | `/delivery/dashboard` | لوحة ميدانية مصممة للهواتف لإدارة المهام المسندة، الاتصال بالعميل، تحديث حالة التسليم، وتسجيل أسباب تعذر التسليم. |
| **العميل (Customer)** | المتجر و `/orders` | تصفح المنتجات، سلة المشتريات، ميزة "اختار لك"، إتمام الطلب، تتبع الشحنة لحظياً، وإلغاء الطلب المتاح. |

## 🚀 المميزات الرئيسية للمشروع

### 1. المتجر والصفحة الرئيسية
- شريط علوي للعروض وسياسة الشحن المجاني فوق 1200 ج.م.
- Header متجاوب مع بحث حي فوري، قائمة أقسام، عداد المفضلة، وسلة مشتريات دائمة.
- Hero Section بصور فائقة الجودة لمنتجات طبيعية وعناوين عربية قوية.
- قسم المنتجات المميزة وقسم أحدث الدفعات من المعاصر والمزارع.
- **ميزة "اختار لك / كوّن باكدجك" (البازار الذكي):** محرك اقتراحات يعتمد على الميزانية (500، 800، 1200، 1800 ج.م) والهدف (مناعة، فطور صحي، هدية، تموين) ويولد باقة متكاملة من قاعدة البيانات مع زر إضافة الباقة كاملة للسلة.
- قسم شفافية التوريد وشرح نموذج البيع حسب الطلب.
- آراء عملاء موثقة بعد الشراء الفعلي.

### 2. الكتالوج والتسوق
- صفحة المنتجات مع فلترة متعددة (القسم، حالة التوفر لدى المورد، السعر) وترتيب حسب الأحدث أو السعر أو التقييم.
- صفحة تفاصيل المنتج: معرض صور متعدد، الحقائق الغذائية، المكونات، المصدر والمنشأ، شارة توفر المورد، والتوصيل التقديري.
- سلة مشتريات دائمة (Persistent Cart) مع حساب شريط الشحن المجاني.
- صفحة إتمام الطلب مع حساب رسوم التوصيل وفقاً لـ 24 محافظة مصرية، واختيار الدفع عند الاستلام (COD) أو InstaPay أو البطاقات.
- صفحة تأكيد الطلب مع تتبع الشحنة لحظياً.

### 3. لوحة إدارة المتجر (`/admin`)
- **المؤشرات المالية الدقيقة:** تمييز واضح وصارم بين إجمالي المبيعات (Gross Revenue)، تكلفة المنتجات من الموردين (COGS)، وصافي الربح التقديري (Net Profit).
- **إدارة الطلبات وسير العمل:** جدول شامل للطلبات مع فلاتر وبحث، وانتقالات منضبطة وفق دورة حياة الطلب (State Machine).
- **محرك التوزيع التلقائي الذكي للطلبات:** يوزع الطلبات الجاهزة تلقائياً على المندوب المعتمد والمتاح ذو الحمل الأقل مع منع التكرار.
- **إدارة المنتجات والتسعير:** إضافة وتعديل وحذف المنتجات، تعديل سعر البيع وسعر شراء المورد، ضبط المخزون، وتحديث الصور.
- **إدارة المندوبين وطلبات الانضمام:** استعراض طلبات المندوبين الجدد والموافقة عليها وتفعيل الحسابات أو إيقافها مؤقتاً.
- **إدارة الموردين:** دليل سري للموردين، أسعار الشراء، تواريخ آخر فحص، وسجل التعامل.
- **سجل التدقيق (Audit Logs):** توثيق كل الإجراءات الإدارية وتغييرات الأسعار وحالات الطلبات.

### 4. لوحة عامل التوصيل (`/delivery/dashboard`)
- مصممة بنهج Mobile-First لسهولة الاستخدام أثناء القيادة والعمل الميداني.
- بطاقات إحصائية للمهام المسندة، والطلبات قيد التوصيل، والمسلمة، والمتعذرة.
- بطاقات الطلبات مع زر اتصال هاتفي مباشر بالعميل `tel:...` وبيانات العنوان بالتفصيل.
- إبراز المبلغ المطلوب تحصيله عند الدفع نقدًا (COD).
- أزرار الحالات: استلام الطرد، خرج للتوصيل، تم التسليم بنجاح، أو تعذر التسليم مع نافذة منبثقة تلزم باختيار سبب دقيق.
- حماية أمنية مشددة: لا يستطيع المندوب الاطلاع على تكلفة شراء المورد أو طلبات المندوبين الآخرين.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend & Fullstack:** Next.js 14 (App Router) مع TypeScript.
- **التصميم وتنسيق الواجهات:** Tailwind CSS بنظام ألوان Forest Green، Warm Ivory، و Muted Gold.
- **الخط العربي:** Google Font Cairo (400, 500, 600, 700, 800) مع fallback محلي وسرعة تحميل فائقة.
- **الأيقونات:** Lucide Icons المتناسقة والخفيفة.
- **الأمان والمصادقة:** جلسات آمنة مشفرة عبر JWT في HttpOnly Cookies، وتشفير كلمات المرور بواسطة `bcryptjs`.
- **قاعدة البيانات المضمنة الفورية:** محرك بيانات علائقي فائق السرعة يعمل محلياً في `data/bazaar-store.json` مع عمليات ذرية (Atomic Writes) وعمليات CRUD كاملة ودعم المعاملات التزامنية.
- **مخطط Supabase PostgreSQL للإنتاج:** يتوفر ملف ترحيل كامل لقاعدة بيانات PostgreSQL السحابية في `supabase/schema.sql` مع سياسات أمان مستوى الصفوف (Row Level Security - RLS).

## 💻 تعليمات التشغيل المحلي (Getting Started)

### 1. تشغيل بيئة التطوير
```bash
npm run dev
```
افتح المتصفح على: [http://localhost:3000](http://localhost:3000)

### 2. بناء نسخة الإنتاج والتحقق
```bash
npm run build
npm run start
```

### 3. تشغيل حزمة الاختبارات الآلية
يحتوي المشروع على حزمة اختبارات شاملة تغطي 22 معياراً دقيقاً (صلاحيات الأدوار، تشفير كلمات المرور، احتساب الأرباح، التوزيع التلقائي، وانتقالات دورة حياة الطلبات):
```bash
node test-suite.js
```

## 🗄️ ترحيل قاعدة البيانات إلى Supabase (Production Deployment)

عند الرغبة في نشر المشروع في بيئة الإنتاج السحابية وربطه مباشرة بـ Supabase:
1. أنشئ مشروعاً جديداً في [Supabase](https://supabase.com).
2. افتح **SQL Editor** في لوحة تحكم Supabase.
3. انسخ محتوى الملف المرفق `supabase/schema.sql` والصقه ونفّذه بالكامل.
4. يشتمل الملف على:
   - كافة الجداول والمفاتيح الأجنبية والقيود والفهارس.
   - سياسات الأمان على مستوى الصف (RLS) التي تضمن عزل بيانات العملاء، وحصر أسعار التكلفة والموردين للمدير فقط.
